# Call-Center-Performance-Dashboard
 About the Project
This project is an interactive Excel dashboard built to analyze call center operations. The goal was to track agent performance, call volumes, and customer satisfaction.

## Tools & Skills Used
* Microsoft Excel
* PivotTables & PivotCharts
* Interactive Slicers
* Dashboard Design (Dark Blue & Gray Theme)

## Key Metrics Analyzed
* **Total Calls:** Counted the total volume of calls handled.
* **Customer Satisfaction:** Averaged the satisfaction ratings.
* **Speed of Answer:** Tracked how fast agents picked up calls.
* **Talk Duration:** Analyzed the average time spent on calls.
* **Filters:** Added a Slicer to filter the entire dashboard by Agent
